# StudyAI — Local AI Study Assistant

StudyAI is a local AI-powered study assistant built with Python, FastAPI, Ollama, Qwen3, and ChromaDB.

## Features
- Ask questions using a local language model.
- Retrieve relevant information from a knowledge base.
- Upload and process supported documents.
- Search documents using semantic embeddings.
- Run automated tests.

## Technology Stack
- Python 3.10
- FastAPI and Uvicorn
- Ollama
- Qwen3 4B
- Qwen3 Embedding 0.6B
- ChromaDB
- pytest and HTTPX
